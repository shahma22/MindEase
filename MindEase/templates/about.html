ℹ️ About MindEase

An AI-powered mental wellness website built for university students.

🎯 Project Aim

MindEase was developed as part of the SEC6201 Undergraduate Project (BEng Software Engineering). The aim is to provide a free, anonymous, AI-powered platform that supports student mental wellness through journaling, mood tracking, sentiment analysis, and evidence-based resources.

⚙️ Technologies Used

  • Backend: Python Flask
  • Sentiment Analysis: TextBlob
  • Frontend: HTML, CSS, JavaScript
  • Database: SQLite

🤖 How the AI Works

MindEase uses TextBlob to calculate a sentiment polarity score for your text. The score ranges from -1.0 (very negative) to +1.0 (very positive). Based on this score your mood is classified as Positive, Negative, or Neutral and an appropriate supportive response is shown.

🔐 Ethical Considerations

  • No account or personal data required — fully anonymous
  • Journal entries can be deleted at any time
  • MindEase is not a substitute for professional therapy
  • Crisis support contacts are visible on every page
